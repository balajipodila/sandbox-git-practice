# Structure Note — Git Fundamentals (Week 5)

## Repository Layout
- README.md → Main description of the repo
- workflow-note.md → Commands practiced and explanations
- structure-note.md → Repo layout and environment notes
- .gitignore → Files and folders ignored by Git

## Environments
- Local Sandbox Repo → Practicing Git commands on my laptop
- GitHub Remote Repo → Central repository for commits and pull requests

## Notes
- Local repo = where I run commands and make changes
- Remote repo = GitHub copy where I push commits
- Branches = separate lines of development (feature-practice, main)
- Commits = snapshots of changes
- Pull Request = way to merge changes into main
