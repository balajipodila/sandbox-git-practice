# Workflow Note — Git Fundamentals (Week 5)

## Commands Practiced

1. git clone https://github.com/balajipodila/sandbox-git-practice.git  
   → Clone repo from GitHub to local system.

2. git checkout -b feature-practice  
   → Create new branch for practice.

3. git add README.md  
   → Stage changes to README file.

4. git commit -m "docs: added Week 3 practice note"  
   → Save snapshot of changes with message.

5. git push origin feature-practice  
   → Push branch and commits to GitHub.

## Notes
- Clone = copy repo locally.  
- Branch = separate line of work.  
- Commit = save changes.  
- Push = upload commits to GitHub.  
- Pull Request = ask to merge branch into main.  
- Conflict = when two branches change same line differently.  
- .gitignore = tells Git which files to skip.
